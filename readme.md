Online data analysis scripts for the FIREBALL-III experiment at the HiRadMat, CERN. Primary author: Hayden Ramm (University of Oxford, correspondence: hayden.ramm@linacre.ox.ac.uk). Additional code by Bryn Lloyd (University of Oxford) and Enrica Soria (CERN). Enrica is co-author for the analysis code dealing with the LDV (laser doppler vibrometer) data- this can be found in the ldvloadmanager.py and ldvopmanager.py files.
